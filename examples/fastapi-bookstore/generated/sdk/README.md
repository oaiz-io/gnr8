# Bookstore API Python SDK

This directory is generated by `gnr8`. Do not edit generated files directly; edit `.gnr8/src/main.rs` or the source service, then run `gnr8 generate`.

## Package

- Language: Python
- Import: `sdk`
- Install: `pip install sdk`
- Base path: `/`
- Operations: 4
- Schemas: 8

## Agent workflow

1. Read `reference.md` in this directory for every operation, schema, error and credential, each operation with its sample.
2. Construct the generated `Client` with the service base URL.
3. Pass typed request models and path/query parameters according to the generated method signatures.
4. Handle generated `ApiError` values for rejected HTTP responses.

## Retries and timeouts

`timeout` bounds each individual attempt, not the whole call: with retries, total wall time can reach `timeout x (max_retries + 1)` plus the waits between them. Total time spent waiting between retries is capped at 60s, so a longer `Retry-After` is honoured only up to that cap. Retry waits are not interruptible.

## Quick start

client = Client(base_url)
result = client.list_books(cursor="gnr8", genre="gnr8", sort="gnr8")
print(result)
