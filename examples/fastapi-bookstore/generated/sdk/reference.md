# Bookstore API Python SDK reference

Generated by `gnr8` for `sdk`. [README.md](README.md) shows how to install it and construct the client.

## Bookstore API

### Operations

- `list_books` — `GET /books/` — List books in one genre.
- `create_book` — `POST /books/` — Add a book to the catalogue.
- `get_book` — `GET /books/{book_id}` — Fetch one book by its identifier.
- `update_book` — `PUT /books/{book_id}` — Update the stored filters for one book.

### Schemas

- `Author`
- `Book`
- `BookFilters`
- `BookFormat`
- `BookOrError`
- `CreatedMessage`
- `ListBooksResponse`
- `OutOfStock`

## `list_books`

`GET /books/`

List books in one genre.

Results are ordered by title and paginated with an opaque cursor. Pass the
cursor from the previous page to continue; omit it to start from the
beginning.

### Parameters

#### Query

| Name | Type | Required |
| --- | --- | --- |
| `cursor` | `string` | no |
| `genre` | `string` | yes |
| `sort` | `string` | no |

### Responses

| Status | Body | Media types |
| --- | --- | --- |
| `200` | `ListBooksResponse` | `application/json` |

### Example

Each value is the example the API declares for it, or else one sampled from the schema, and satisfies every declared constraint. Credentials are placeholders — `{apiKey}`, `{token}`, `{base64(username:password)}` — and the code samples take them and the base URL as variables. Paths start at the server root; a server URL with a path prefix prepends it to every path.

#### HTTP

```http
GET /books/?cursor=gnr8&genre=gnr8&sort=gnr8 HTTP/1.1
```

```http
HTTP/1.1 200
content-type: application/json

{
  "books": [
    {
      "author": {
        "bio": "gnr8",
        "name": "gnr8"
      },
      "format": "hardcover",
      "id": 7,
      "rating": 7,
      "tags": [
        "gnr8"
      ],
      "title": "gnr8"
    }
  ],
  "next_cursor": "gnr8",
  "total": 7
}
```

#### Python — `sdk`

```python
from sdk import Client

client = Client(base_url)
result = client.list_books(cursor="gnr8", genre="gnr8", sort="gnr8")
print(result)
```

Iterating over every item of every page:

```python
from sdk import Client

client = Client(base_url)
for item in client.iter_list_books(genre="gnr8", sort="gnr8"):
    print(item)
```

#### CLI — `bookstore`

`bookstore books list`

```sh
bookstore books list --genre fiction
```

### Pagination

- Mode: `cursor`
- Items field: `books`
- Cursor parameter: `cursor`
- Next-cursor field: `next_cursor`
- Stops when the next cursor is absent, empty or null.
