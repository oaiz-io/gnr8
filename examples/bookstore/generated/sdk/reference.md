## Bookstore API

### Groups

#### books

Browse and manage the catalogue

- `listBooks` — `GET /books` — Returns every book in the catalogue.
- `createBook` — `POST /books` — Adds a book to the catalogue.

- `getBook` — `GET /books/{id}` — Returns one book by its identifier.
- `updateBook` — `PUT /books/{id}` — Replaces the mutable fields of one book.
