# Bookstore API Rust SDK

This directory is generated by `gnr8`. Do not edit generated files directly; edit `.gnr8/src/main.rs` or the source service, then run `gnr8 generate`.

## Package

- Language: Rust
- Import: `bookstore_sdk`
- Install: `cargo add bookstore-sdk`
- Base path: `/`

## Agent workflow

1. Read `reference.md` in this directory for every operation, schema, error and credential, each operation with its sample.
2. Construct the generated `Client` with the service base URL and a `Transport` that sends one HTTP exchange.
3. Pass typed request models and path/query parameters according to the generated method signatures.
4. Handle generated `ApiError` values for rejected HTTP responses.

## Retries and timeouts

`timeout` bounds each individual attempt, and the `Transport` enforces it: with retries, total wall time can reach `timeout x (max_retries + 1)` plus the waits between them. Total time spent waiting between retries is capped at 60s, so a longer `Retry-After` is honoured only up to that cap. Retry waits are not interruptible.

## Quick start

Calling `listBooks` (`GET /books`), as `reference.md` prints it:

```rust
use bookstore_sdk::Client;
use bookstore_sdk::ListBooksParams;

let client = Client::builder(base_url, transport).api_key_for("ApiKeyAuth", api_key).build();
let result = client.list_books(&ListBooksParams { genre: Some("gnr8".to_string()), ..ListBooksParams::new() })?;
println!("{result:?}");
```
