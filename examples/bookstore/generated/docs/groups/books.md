# books

Browse and manage the catalogue

## Operations

- [`listBooks`](../operations/list-books.md) — `GET /books` — Returns every book in the catalogue.
- [`createBook`](../operations/create-book.md) — `POST /books` — Adds a book to the catalogue.
- [`deleteBook`](../operations/delete-book.md) — `DELETE /books/{id}` — Permanently removes one book from the catalogue.
- [`getBook`](../operations/get-book.md) — `GET /books/{id}` — Returns one book by its identifier.
- [`updateBook`](../operations/update-book.md) — `PUT /books/{id}` — Replaces the mutable fields of one book.
