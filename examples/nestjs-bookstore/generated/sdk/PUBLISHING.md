# Publishing TypeScript SDK

Package: `@example/bookstore-sdk`
Version: `0.1.0`

`gnr8` never stores registry credentials and never uploads packages. Run these commands in this generated SDK directory after reviewing the generated files.

1. `npm install`
2. `npm run build`
3. `npm pack --dry-run`
4. `npm publish --dry-run`
5. Publish with your own npm credentials when the dry run matches expectations.
