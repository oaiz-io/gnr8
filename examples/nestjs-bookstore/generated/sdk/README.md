## Retries and timeouts

`timeoutMs` bounds each individual attempt, not the whole call: with retries, total wall time can reach `timeoutMs x (maxRetries + 1)` plus the waits between them. Total time spent waiting between retries is capped at 60s, so a longer `Retry-After` is honoured only up to that cap. Pass `signal` to interrupt a retry wait.
