# Bookstore API TypeScript SDK reference

Generated by `gnr8` for `@example/bookstore-sdk`. [README.md](README.md) shows how to install it and construct the client.

## Bookstore API

### Operations

- `listBooks` — `GET /books/` — List books in one genre.
- `createBook` — `POST /books/` — Add a book to the catalogue.
- `getBook` — `GET /books/{bookId}` — Fetch one book by its identifier.
- `updateBook` — `PUT /books/{bookId}` — Update the stored filters for one book.

### Schemas

- `AuthorDto`
- `BookDto`
- `BookFilters`
- `BookFormat`
- `BookOrError`
- `CreatedMessage`
- `ListBooksResponse`
- `OutOfStockDto`

## `listBooks`

`GET /books/`

List books in one genre.

Results are ordered by title and paginated with an opaque cursor. Pass the
cursor from the previous page to continue; omit it to start from the beginning.

### Parameters

#### Query

| Name | Type | Required |
| --- | --- | --- |
| `cursor` | `string` | no |
| `genre` | `string` | yes |
| `sort` | `string` | no |

### Responses

| Status | Body | Media types |
| --- | --- | --- |
| `200` | `ListBooksResponse` | `application/json` |

### Example

Each value is the example the API declares for it, or else one sampled from the schema, and satisfies every declared constraint. Credentials are placeholders — `{apiKey}`, `{token}`, `{base64(username:password)}` — and the code samples take them and the base URL as variables. Paths start at the server root; a server URL with a path prefix prepends it to every path.

#### HTTP

```http
GET /books/?cursor=gnr8&genre=gnr8&sort=gnr8 HTTP/1.1
```
